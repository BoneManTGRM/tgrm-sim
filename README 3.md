# TGRM Sim Demo — Reparodynamics

Minimal GitHub Pages demo and Python script showing TGRM micro-repairs with an adaptive threshold (τ).
Replicates the ~40% efficiency gain vs a standard pipeline under default parameters.

## Run locally
```bash
python tgrm_sim.py
python tgrm_sim.py --tau 0.6 --err 0.2 --repeats 50
```

## GitHub Pages
Enable Pages for this repo (Settings → Pages → Source: Deploy from branch → Branch: `main` → `/root`).  
Your site will appear at: `https://<your-username>.github.io/tgrm-sim-demo/`
